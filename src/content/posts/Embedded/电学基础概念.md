# 电流基础原理
## 基本概念

### 电流 A


 ```
 定义：电荷在单位时间内通过导体横截面的流动量
 字母表示：I
 单位：安培（A），毫安 mA
 ```

### 电压 V

```
定义：电荷在单位时间内通过导体横截面的流动量
字母表示：U
单位：伏特（V），千伏（Kv），微伏（mV）
```

### 电阻

```
定义：导体对电流的阻碍作用就叫该导体的电阻
字母表示：R
单位：欧姆
```

### 电路

```
通路
短路
```


### 交流电和直流电

```
直流电：电流的方向和大小保持不变
交流电：电流的方向和大小周期性变化
```

### 强电和弱电

```
安全电压：直流：24V；交流：36V
强压：传输能量的电
弱电：传输信号的电
```

## 常见定律


### 欧姆定律

```
I = R / U
R = U / I
U = R * I
```
